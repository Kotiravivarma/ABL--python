# Python Activity-Based Learning (ABL)

This repository contains beginner-friendly Python programs for the first-year B.Tech CSE (AIML) syllabus.

## Project folders

Each numbered folder contains a Python program and supporting documentation, algorithm, pseudocode, flowchart description, and test cases.

1. Student Marks and Grade Calculator
2. Arithmetic Calculator
3. Multiplication Tables and Patterns
4. Shopping Bill Calculator
5. String Analyzer
6. List Analyzer
7. Attendance Checker
8. Set Operations
9. Expense Tracker
10. Login Validator

## Syllabus alignment

- Unit I: computational thinking, algorithms, flowcharts, pseudocode, variables, data types, input/output, type conversion, operators, expressions, and coding practices.
- Unit II: conditionals, loops, strings, string methods, formatting, and pattern generation.
- Unit III: lists, nested lists, tuples, tuple unpacking, sets, set operations, and membership testing.

## Running a program

1. Open the required project folder in PyCharm.
2. Open main.py.
3. Run the file and enter the requested values.
4. Compare the result with the test cases in that folder.

Note: Verify the proposed program list against the faculty-provided list of 100 case studies before final submission.
