# Student Marks and Grade Calculator

## Problem statement
Write a Python program to accept a student's marks, calculate the total and average, and display a grade.

## Objective
Practise input/output, type conversion, arithmetic operators, loops, and conditional statements.

## Assumptions
- The number of subjects must be a positive integer.
- Each subject mark must be between 0 and 100.
- Grade boundaries are illustrative and can be changed to match faculty rules.

## Algorithm summary
1. Read the number of subjects.
2. Validate that it is positive.
3. Read each mark and validate the range.
4. Add valid marks to the total.
5. Calculate the average.
6. Use if-elif-else to assign a grade.
7. Display total, average, and grade.

## Grade criteria
- A: average >= 90
- B: average >= 80
- C: average >= 70
- D: average >= 60
- E: average >= 40
- F: average < 40

## Concepts used
Variables, int and float conversion, input(), print(), for loop, break, arithmetic and relational operators, logical operator or, formatted strings, and if-elif-else.

## Conclusion
This program demonstrates how Python can process marks and make grade decisions using basic control structures.
